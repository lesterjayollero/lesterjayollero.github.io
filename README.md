# Personal Website 

This repository contains the source code for Lester Jay Ollero's personal academic and professional website.

The website serves as a digital portfolio showcasing research, publications, projects, awards, and interactive work related primarily to transportation engineering, traffic engineering, public transportation, and urban mobility.

The site is designed as a lightweight, responsive, and minimalist web experience using standard front-end technologies.

The website is built primarily with:

HTML5 — page structure and content
CSS3 — layout, responsive design, and styling
JavaScript — interactions and simulations
Canvas API — interactive traffic-flow visualizations
MathJax — mathematical notation and transportation engineering equations
GitHub Pages — website hosting

<strong>Running Locally</strong>

Because the website uses standard HTML, CSS, and JavaScript, it can be run locally without a backend server.

Clone the repository
git clone https://github.com/lesterjayollero/lesterjayollero.github.io.git
Enter the project directory
cd lesterjayollero.github.io

Open the website

Open:

index.html

in a web browser.

Alternatively, use a local development server such as VS Code Live Server for a more representative development environment.

Deployment

This repository follows the standard GitHub Pages structure for a personal site:

username.github.io

GitHub Pages automatically publishes the website from the repository, making changes available through:

https://lesterjayollero.github.io

GitHub's documentation confirms that repositories named username.github.io can be used as personal GitHub Pages websites.

Updating the Website

To update the website:

Modify the relevant HTML, CSS, JavaScript, or image files.
Test the changes locally.
Commit the changes.
Push them to the main branch.
GitHub Pages will publish the updated website.

Example:

git add .
git commit -m "Update website"
git push origin main
